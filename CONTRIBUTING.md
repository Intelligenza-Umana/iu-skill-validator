# Contributing

This is an open-source project within Intelligenza Umana. See the [organization contribution guide](https://github.com/Intelligenza-Umana/intelligenza-umana/blob/main/CONTRIBUTING.md).

Discuss scope and design in an issue before substantial changes. Start from the [project proposal](docs/PROPOSAL.md).

1. Create a feature branch (or fork the repository).
2. Keep changes focused and include relevant tests.
3. Open a pull request targeting `main`, linking the relevant issue.
4. Describe what changed, how it was verified, and what remains untested.
5. Address review feedback before merging.

Keep static checks and actual host behavior distinct. Never include credentials, private data or unsupported compatibility claims. Use synthetic fixtures and controlled test environments.

The implementation language and tooling will be agreed during initial design.
